# Лендинг платформы «Татсфера» — дизайн

Дата: 2026-10-15 · Ветка: `future` · Статус: реализовано (ожидает релиза в `main`)

## Задача

Витрина информационной системы «Татсфера» для публикации на `tatsphera.ru`. Сейчас
корневой `index.html` — технический лоадер, который сразу редиректит на `login.html`.
Нужна публичная страница-лендинг с описанием платформы и входом в презентацию
стажировочной площадки (через авторизацию).

## Цели

- Публичный лендинг (витрина платформы) как главная страница `tatsphera.ru`.
- Единый бренд-язык с существующими страницами (`deck.html`, `login.html`).
- Переход на презентацию стажировочной площадки через авторизацию.
- Работа в ветке `future`; слияние в `main` — по готовности к релизу.

## Не-цели (YAGNI)

- Не менять `login.html` и `deck.html` (цепочка авторизации сохранена).
- Не рефакторить устаревшие файлы (`about.html`, `atp.html`, `contact.html`, `base.html`,
  `script.js`, `style.css`, `palitra.html`, `index copy.html`).
- Не выносить общий `brand.css` (сохраняем конвенцию «каждый файл самодостаточен»).

## Поток входа

```
index.html (лендинг, публичный)
   └─ CTA «Презентация стажировочной площадки» → login.html
        └─ Supabase auth → deck.html (защищён сессией)
```

- `index.html` перестаёт быть лоадером; становится лендингом.
- `login.html` (форма входа) и `deck.html` (колода) остаются без изменений.
- CTA-кнопка одна (в hero) — из шапки дублирующая кнопка удалена.

## Структура страницы

1. **Шапка** (sticky, тёмная, blur): знак ЦЦТ + словесный знак «Татсфера»; навигация
   (О платформе / Решения / Ценность / Внедрение / Контакты); герб РТ справа.
   На ≤460px герб скрывается; на ≤820px навигация скрывается.
2. **Hero** (тёмный `#0B3C49`): заголовок «Татсфера. Управление регионом на основе
   данных», лид, две CTA (презентация + якорь «Прикладные решения») и орбитальная
   сфера данных.
3. **Метрики** (4): 130 млн чеков/мес · 5,4 млрд товаропозиций/год · 19 млрд записей ·
   98,75 % удовлетворённости обучением.
4. **О платформе**: 6 карточек-подсистем (со стеком) + 4 ключевые возможности.
5. **Прикладные решения**: 8 кейсов ведомств (чередование цветов yellow/purple/outline).
6. **Ценность для региона**: 6 ценностей + блок «Центр компетенций ЦЦТ» (4 задачи).
7. **Внедрение**: 6 шагов + роли (ЦЦТ РТ → функциональный заказчик → подрядчик).
8. **Подвал**: контакты, строка логотипов, мета-строка.

## Орбитальная сфера данных

Декоративный сигнатурный элемент hero (8 источников), вращается; при
`prefers-reduced-motion` анимация отключается.

- Внешнее кольцо (6): Госуслуги РТ, Народный контроль, Обращения граждан,
  **Аналитика товарных потоков (акцент — жёлтая заливка)**, ФНС · кассовые чеки, ГИС МЖФ.
- Внутреннее кольцо (2): Электронная очередь, СМЭВ.
- Ядро: «Единое окно данных».
- Единственный жёлтый акцент — «Аналитика товарных потоков».

## Технически

- Один самодостаточный `index.html` (inline CSS, inline SVG), изображения из `images/`.
- SEO/OG-мета, `canonical` → `https://tatsphera.ru/`, `favicon`.
- Адаптив: 3→2→1 колонки; проверено на 1440 / 1024 / 390 px.
- `prefers-reduced-motion` (отключение анимации сферы), print-стили.
